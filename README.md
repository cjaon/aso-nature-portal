# ASO+ NATURE 足醫中心 · 3D列印客製鞋墊客訴處置、交件追蹤與門市 Wiki 知識系統

針對 3D 列印客製鞋墊（自然足專案）與專業售後服務打造的**互動式 Web 系統原型**。系統緊密結合「ASO+ NATURE 足醫中心門市網絡」、「正全義肢鞋墊製造商」、「專業顧問」與「Jason 主管」，針對常見的**「鞋墊做錯」**、**「尺寸不符」**、**「客人穿著不適」**提供標準化 SOP、原因技術診斷、後續交件履約追蹤，以及門市 Wiki 知識庫即時查閱機制。

   - 顧客以手機相機掃碼後自動跳轉至進度查詢頁並調閱四階段進度時序圖。
3. **手機拍照上傳與 Canvas 觸控圈選標註工具**：
   - 支援門市 iPad 或手機拍照與相片上傳。
   - 內建 HTML5 Canvas 觸控畫布，提供紅圈、方向箭頭、自由畫筆與清除重繪功能。
   - 圈選完成後一鍵壓縮輸出並自動掛載至案件診斷佐證清單。
4. **30 間門市品質與客訴多維度戰情儀表板**：
   - 整合於後台「統計戰情」切換視圖。
   - 門市客訴 Top 排行長條圖、問題成因佔比、權責處理人負荷分佈、常見鞋款與痛點熱度分析。
5. **工廠端多選批次處置與物流單號快速登錄**：
   - 案件清單支援多選核取方塊與浮動批次工具列。
   - 正全工廠與管理員可一次批次將複數案件變更為「重製/修磨中」、「完工待交件」，並同步登錄物流單號。
6. **D+3 / D+14 售後追蹤排程清單與一鍵關懷日誌**：
   - 獨立過濾「售後追蹤期」待辦隊列，附帶到期狀態標籤（即將到期、今日追蹤、逾期）。
   - 提供「初穿良好」、「微調預約」、「電話未接」快速填報按鈕，自動更新回訪日誌與結案判定。

## 📋 核心功能模組

### 1. 最新公告與 3D 取模規範專區
- 📣 **製程最新公告**：工廠原物料升級（如 Poron 雙密度 PR-V2 導入）、排程維護與交期公告。
- 📐 **3D 取模與量測規範**：半負重膝踝 90° 垂直中立位標準 SOP、泡棉盒防踩穿退件示範、原廠鞋墊輪廓套量要求。
- 📋 **門市服務 SOP**：取模、交件衛教與磨合期宣導指引。

### 2. 門市 Wiki 知識庫 (即時處置字典)
- 門市人員在櫃檯面對客人疑難雜症時，可直接搜尋鞋款（如 ASICS、HOKA、皮鞋）或症狀（如前掌擠腳、足弓刺痛、做錯）。
- **明確標記「誰處理」**：
  - 🏭 **正全義肢鞋墊製造商**：CNC 雕刻參數校正、規格錯誤加急 100% 免費重製、雷射裁切。
  - 🩺 **專業顧問**：生物力學診斷、舟狀骨降高微調、足壓重測與衛教。
  - 👤 **Jason**：重大爭議仲裁、重製工單覆核、Wiki 案例審定。
  - 🛠️ **門市技師**：砂輪機 45° 倒角現場微調（15分鐘立等可取）。

### 3. 客訴案件受理與問題填報表單
- 門市代號與名稱選取連動。
- **足部痛點視覺化多選**：點選標記內側足弓過高、前掌起皺、大拇趾蹠骨痛、後跟杯鬆脫等。
- **智能關聯提示**：填表時即時在右側提示過往 Wiki 相似案例與成功解法。
- 支援實物照片拖曳上傳模擬。
- 自動生成專屬追蹤案號（例：`CMP-20260905-0102`）。

### 4. 案件進度查詢 (四階段視覺時序圖)
- 輸入案件編號即可調閱即時進度：
  1. 案件受理 ➔ 2. 診斷處置中 ➔ 3. 完工待交件 ➔ 4. 售後追蹤與結案
- 顧客與門市可透明查閱受理門市、技師檢測結果、核定處置手段與黑貓物流單號。

### 5. 後台管考中心與工單列印（受密碼保護）
- **KPI 總覽卡片**：受理總數、待受理/診斷中、重製/修磨中、售後追蹤期、已結案。
- **處置抽屜 (Drawer Modal)**：
  - 顯示受理門市與顧客主訴。
  - 指派責任人（正全 / 顧問 / Jason / 門市技師）。
  - 記錄技術診斷歷程與原因剖析。
  - 登錄交件物流方式與單號。
  - 登記 D+3 初期試穿回訪與 D+14 滿意度結案。
  - **一鍵沉澱收錄至 Wiki**：勾選後自動轉化為門市最新知識條目。
- **列印處置派工單**：包含 ASO Logo、受理門市、原單資料、技師診斷、痛點勾選與出廠 QC 簽章表格。
- **CSV 報表匯出**：一鍵下載完整客訴清冊（含門市代號與名稱）。
